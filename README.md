### 1. Overview and Offline-First Architecture
StokDepom (StockPulse) prioritizes user privacy and data security. The app is built with a strict **100% Offline-First** philosophy:
- All inventory data, products, quantities, prices, categories, storage locations, and transactions are stored strictly locally on your device using an ACID-compliant SQLite database.
- We do not operate external tracking servers or cloud sync databases that collect your business data.
- You retain complete ownership of your inventory data.

### 2. Device Permissions
- **Camera (`CAMERA`):** Used exclusively for real-time barcode and QR code scanning. Camera frames are processed on-device and are never recorded, saved, or uploaded.
- **Local Storage / File Sharing:** Used strictly when you intentionally export inventory reports or transaction histories to CSV.
